The Medical City South Luzon · IT Department

~265 hrs practicum engagement

During a 265-hour onsite practicum in the IT Department, I designed and built the frontend for the IT Management System — an internal web application that digitizes the department's asset management and operational workflows. I contributed across the full stack while also supporting helpdesk operations and network infrastructure.

HTML/CSSJavaScriptTypeScriptNode.jsXAMPPMySQLHelpdeskNetworking

Challenge

The IT Department relied on manual asset tracking and paper-based processes, making it difficult to monitor inventory, manage user access, retrieve records, and maintain audit trails efficiently.

Solution

Built a web-based IT Management System with purchase request tracking, file maintenance, user management, end-user deployment tracking, reports generation, and audit logging — streamlining the department's operational workflows.

Impact

Created a centralized platform for managing IT assets and user access, streamlining record-keeping, simplifying reporting, and reducing dependency on manual spreadsheets and paper forms.

Public-Safe System Overview

Internal system: source code, operational data, and detailed workflows remain confidential.

Key Contributions

  • Purchase request module — built asset procurement tracking with vendor details, quantities, and request status monitoring.
  • File maintenance system — centralized configurable dropdown entries (brands, vendors, departments, asset types) for scalable data management.
  • User management — created account creation and role assignment with configurable permissions and temporary access grants.
  • End-user deployment tracking — recorded asset assignment history to maintain accountability and track equipment deployment.
  • Reports generation — enabled customized report generation with filters, field selection, and CSV export for data-driven decisions.
  • Audit logs — implemented activity tracking for create, edit, delete, and update actions to ensure accountability and simplify auditing.
  • IT helpdesk support — provided daily technical assistance to hospital staff including printer, network, and application-related concerns.
  • Network infrastructure — performed cable termination (RJ45/RJ11), PC setup, application deployment, and LAN line preparation.
